## Prueba de usuario `intranet` de solo lectura

### Configuración

Se creó el usuario:

```sql
CREATE USER 'intranet'@'%' IDENTIFIED BY 'Intranet2026!';
```

y se concedió únicamente permiso de lectura sobre la base de datos:

```sql
GRANT SELECT ON daniela_proyecto.* TO 'intranet'@'%';
```

### Verificación de privilegios

Se ejecutó:

```sql
SHOW GRANTS FOR 'intranet'@'%';
```

Resultado:

```text
GRANT USAGE ON *.* TO `intranet`@`%`
GRANT SELECT ON `daniela_proyecto`.* TO `intranet`@`%`
```

### Prueba de lectura

Se inició sesión con el usuario `intranet` y se ejecutó:

```sql
SELECT id, nombre, precio
FROM productos
LIMIT 5;
```

La consulta devolvió correctamente los productos almacenados en la base de datos.

### Prueba de modificación

Se intentó ejecutar:

```sql
UPDATE productos
SET precio = 999
WHERE id = 1;
```

MySQL rechazó la operación con el error:

```text
ERROR 1142 (42000):
UPDATE command denied to user 'intranet'@'localhost'
for table 'productos'
```

### Resultado

El usuario `intranet` puede consultar los datos de la base de datos, pero no puede modificarlos.

### Estado

**OK**
